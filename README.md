# 四级训练工作台（CET-4 Trainer）

一个**零依赖、单文件、可离线**的大学英语四级刷题 / 模考训练器。全部代码、题库、离线词典内联进一个 `index.html`，双击即用，数据存在浏览器本地。

## 功能

- **单题训练**：听力 / 阅读 / 选词填空 / 段落匹配，按题型、考点刷题，做完立刻出答案与依据
- **套卷模考**：20 套真题 + 4 套模考整卷限时作答，交卷统一判分，710 分制估算
- **选词填空**：整篇十空填满才统一公布答案，空位可点击弹词库填写
- **写作诊断**：离线规则引擎逐句找错（拼写 / 语法 / 搭配 / 标点），给出修改建议
- **单词本**：划词查词（离线词典 14604 条 + 联网补漏）、黄标 / 红标、错题本
- **移动端**：PWA（可添加到主屏幕）、触屏长按取词、点词即译、底部抽屉查词
- **数据自检**：存储可写性检测、页面版本自更新（防缓存旧版）、导出备份 / 备份码恢复

## 快速开始

**方式一：直接用** —— 下载 `dist/index.html`，双击用浏览器打开即可，无需安装任何东西。

**方式二：本地起服务**（PWA 功能需要 https 或 localhost）：

```bash
npx serve dist
# 或
python -m http.server -d dist 8000
```

**从源码构建**（需要 Node.js，无任何 npm 依赖）：

```bash
node build.js   # 产出 dist/index.html
```

## 设计说明

- **单文件架构**：构建脚本把 CSS / JS / 题库 / 词典全部内联进一个 HTML，方便分发（发给别人只需发一个文件）
- **数据全在本地**：学习记录存 `localStorage`，设置页可导出备份码；换设备用「恢复备份」迁移
- **防缓存**：页面内置版本号，启动时抓取 `ver.txt` 比对，不一致自动带新参数重载——解决微信等内置浏览器缓存旧版的问题
- **触屏取词三级兜底**：`caretRangeFromPoint` → `Range.getClientRects()` 逐字符命中 → 元素首词；长按 0.5 秒不等 `touchend`，适配鸿蒙等接管手势的系统
