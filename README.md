# 四级训练工作台（CET-4 Trainer）

一个**零依赖、单文件、可离线**的大学英语四级刷题 / 模考训练器。全部代码、题库、离线词典内联进一个 `index.html`，双击即用，数据存在浏览器本地。

**[▶ 在线试用](https://clueless-ux.github.io/cet4-trainer/)** ｜ [下载单文件](https://clueless-ux.github.io/cet4-trainer/index.html)（右键另存为，双击即可离线使用）

## 功能

- **单题训练**：听力 / 阅读 / 选词填空 / 段落匹配，按题型、考点刷题，做完立刻出答案与依据
- **套卷模考**：20 套真题 + 4 套模考整卷限时作答，交卷统一判分，710 分制估算
- **选词填空**：整篇十空填满才统一公布答案，空位可点击弹词库填写
- **写作诊断**：离线规则引擎逐句找错（拼写 / 语法 / 搭配 / 标点），给出修改建议
- **单词本**：题干、选项和原文里的英文可划词查询（离线词典 14604 条 + 联网补漏），并加入黄标或红标复习
- **背单词**：练习勾选或按标记筛出的单词，也可从 1,800 个精选四级重点词里每轮随机抽 12 个。支持英选中、朗读、翻看释义和重练本轮错词
- **听力原文**：13 套带听力的真题均配有分篇转写稿。单题作答后或套卷交卷后，可在题目下展开相应原文和已收录的录音问题
- **考点图谱**：拖动旋转三维关系图，滚轮或双指缩放，拖动可调整节点位置，点节点可打开考点和专项练习
- **图谱动效**：首页学习图谱的光点环绕移动，三维图谱的光点沿考点连线流动。两处共用动效开关，默认遵循系统的「减少动态效果」设置
- **移动端**：PWA（可添加到主屏幕）、题目英文长按取词、点词即译、底部抽屉查词
- **数据自检**：存储可写性检测、页面版本自更新（防缓存旧版）、导出备份 / 备份码恢复

## 快速开始

**方式一：直接用** —— 下载 `dist/index.html`，双击用浏览器打开即可，无需安装任何东西。

**方式二：本地起服务**（PWA 功能需要 https 或 localhost）：

```bash
npx serve dist
# 或
python -m http.server -d dist 8000
```

**从源码构建**（需要 Node.js，无任何 npm 依赖）：

```bash
node build.js   # 产出 dist/index.html
```

## 目录结构

```
├── build.js            # 打包脚本：把 src/ 全部内联成单文件 dist/index.html
├── src/
│   ├── desk_shell.html # HTML 骨架（含注入占位符）
│   ├── desk_app.js     # 全部应用逻辑（约 200KB）
│   ├── desk_style.css  # 样式
│   ├── point_graph.js  # 三维考点关系布局和交互
│   ├── essay.js        # 写作诊断引擎（离线规则式）
│   ├── desk_data.json  # 真题题库 + 考点 + 解析
│   ├── listening_transcripts.json # 听力音频转写，按卷和题号分篇
│   ├── core_words.txt  # 背词练习的四级精选词
│   ├── mock_data.json  # 模考卷
│   ├── dict_final.txt  # 离线英汉词典（14604 条）
│   ├── spell_words.txt # 拼写检查词表
│   └── manifest.webmanifest / sw.js / icon-*.png  # PWA 三件套
└── dist/               # 构建产物（已提交，克隆即用）
```

## 设计说明

- **单文件架构**：构建脚本把 CSS / JS / 题库 / 词典全部内联进一个 HTML，方便分发（发给别人只需发一个文件）
- **数据全在本地**：学习记录存 `localStorage`，设置页可导出备份码；换设备用「恢复备份」迁移
- **防缓存**：页面内置版本号，启动时抓取 `ver.txt` 比对，不一致自动带新参数重载——解决微信等内置浏览器缓存旧版的问题
- **触屏取词三级兜底**：`caretRangeFromPoint` → `Range.getClientRects()` 逐字符命中 → 元素首词；长按 0.5 秒不等 `touchend`，适配鸿蒙等接管手势的系统
